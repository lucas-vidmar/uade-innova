# Feature: Global Search for Knowledge (User Story #54)

**Status**: Completed
**Business Impact**: Students can discover relevant concepts faster by searching across the full subject knowledge base in one action.

## Key Milestones
- [x] Added a dedicated global search API scoped to the active subject index.
- [x] Limited retrieval to transcript and bibliography materials to align with academic intent.
- [x] Added a student dashboard global search bar with ranked results and direct class navigation.
- [x] Validated behavior with backend unit tests and a Chrome/Chromium browser test.

## Summary
The student dashboard now includes a global search experience that queries the entire subject index and returns ranked matches from transcripts and bibliography assets. Results include contextual snippets, relevance indicators, and quick links to the related class context.
