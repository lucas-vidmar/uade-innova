# Feature: Academic Deadline Management (User Story #56)

**Status**: Completed
**Business Impact**: Teachers can link deadlines to classes and students see reminders on the dashboard and calendar before work is due.

## Key Milestones
- [x] Added deadline storage and retrieval APIs.
- [x] Added teacher UI to create and edit class-linked deadlines.
- [x] Surfaced deadlines on the student dashboard and calendar.
- [x] Added reminders for the day before and the day of the deadline.
- [x] Verified the create-link-display flow with backend and browser tests.

## Summary
Deadlines are now managed as class-linked academic items. Teachers can configure them from the dashboard, and students receive visibility in the main dashboard, calendar, and reminder notifications close to the due date.
